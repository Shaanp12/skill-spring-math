HOW TO TEST ON WINDOWS
1. Extract all files.
2. Double-click “Start Skill Spring Math.bat”.
3. Keep the command window open.

WHAT STILL REQUIRES AN ONLINE SERVICE
Real email/Google student accounts, cloud syncing across devices, teacher classes,
parent dashboards, leaderboards, assignments, and an admin content editor require
a database and authentication service such as Supabase or Firebase. Those cannot
be safely embedded as fake local features. The static app keeps progress on each
browser and now allows students to export/import it.

HOW TO PUBLISH
Upload this extracted folder to the same Netlify site. The permanent site link
can remain unchanged for every later update.
